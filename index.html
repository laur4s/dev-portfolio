Drawing Task

Task

This task is about drawing a circle or an arbitrary .svg file on a whiteboard using a Universal Robots UR10e with a 3D printed marker holder as a tool.

Project Insights & Skills

Core Competencies

  • Robot Simulation: Gained proficiency in RoboDK, bridging the gap between virtual planning and physical execution.
  • Workflow Optimization: Developed an understanding of why simulation is critical in HRI to ensure safety and precision.
  • Rapid Prototyping: Streamlined the process of converting .svg graphics into executable robot paths.

Technical Troubleshooting

  • Software Debugging: Resolved critical script generation errors by diagnosing version incompatibilities.
  • Resilience: Overcame deployment hurdles by implementing custom code patches to ensure script portability.

Key Takeaways

Hardware Familiarity: Strengthened hands-on skills in manual robot control via the Control Panel (Teach Pendant).
Adaptability: Proven ability to quickly master new robotic tools and documentation practices, making it an ideal foundational project for collaborative robotics.

Impedance-control Task

Task

This task is about teaching a Franka Research 3 to perform a certain motion and afterwards executing this movement to erase a drawn image on a whiteboard.

Project Insights & Skills

Core Competencies

  • Collaborative Robotics: Implemented Lead-Through Teaching with a Franka Emika arm, ensuring safe and intuitive human-robot interaction.
  • Dynamic Control: Applied Impedance Control to balance the stiffness required for erasing with the compliance needed for safe interaction.
  • Real-Time Data Logging: Developed a system to capture and save joint values in real-time to .csv formats for precise trajectory playback.

Technical Troubleshooting

  • Stiffness Optimization: Fine-tuned the control parameters to prevent the robot from "sticking" to the whiteboard while maintaining enough force to erase.
  • Process Automation: Authored a .sh shell script to provide a guided, step-by-step execution flow, simplifying complex command-line interactions for the user.

Key Takeaways

Safety & Compliance: Mastered the concept of Impedance Control, where the robot follows a trajectory but yields to external human force and returns to its path once released.
End-to-End Workflow: Successfully integrated recording, storage, and playback phases into a single, user-friendly robotic application.

Task-Board Manipulation

Task

This task is about performing the first tasks of the Robothon challenge 2025 on a Franka FR3 robot equipped with an Intel Realsense D435i camera. The robot should press buttons according to a speed and light test on an electronic task board. The concrete description can be found in the README below.

Project Insights & Skills

Core Competencies

  • Perception & Vision: Integrated an Intel RealSense camera with the Franka FR3 to perform real-time object detection of taskboard components (buttons) using openCV.
  • Motion Planning: Leveraged MoveIt 2 to manage complex trajectory planning, ensuring the robot could navigate between home positions and different task targets.
  • System Integration: Developed a full-stack robotics application in ROS2, utilizing Gazebo and RViz for high-fidelity simulation and visualization of the robot's environment.
  • Service-Oriented Architecture: Designed the execution logic as a callable ROS2 Service, allowing for modular and triggered task performance.

Challenges & Solutions

  • Hardware-Software Gap: Diagnosed and addressed motion discontinuity errors on the physical FR3 robot, gaining insight into the differences between idealized simulations and real-world hardware constraints.
  • Resilient Debugging: Maintained high endurance while troubleshooting the communication bridge between ROS2 and the physical controller before transitioning to the simulation to meet the project goals.
  • Proactive Workflow Ownership: Assumed central responsibility for the development pipeline ensuring the project reached a functional milestone despite limited hardware availability.

Key Takeaways

Enhanced ROS2 Understanding: Deepened understanding of ROS2 communication patterns (Nodes, Topics, and Services) and their application in industrial-style challenges.
Resilience in Deployment: While the simulation was a success, the real-world trial provided important experiences in debugging low-level controller errors and sensor calibration.
